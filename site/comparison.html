Compare firmware and music players

Already own a Snowsky ECHO?

The player, headphone jacks, and Bluetooth hardware stay the same. Here’s what changes with the firmware.

FiiO stock

Ready to use out of the box. Version 2.0.0 has M3U playlists, favorites, preset EQ, digital filters, USB DAC mode, and playback of DSD files.

FiiO release notes →

Podium

Cover Flow, gapless albums, and chaptered audiobooks. You can set separate EQ for each headphone jack and build themes in a browser. This comparison uses version 4.6.4.

Podium →

Gnarlyr

Reorder a queue, save it as a mixtape, and set up each pair of headphones. Gnarlyr adds speech tools and converts supported DSD to PCM.

Gnarlyr features →

Return to FiiO firmware

The documented return on a working ECHO uses FiiO’s original firmware file. If the player won’t start, there’s a recovery mode called maskrom. We used it to restore FiiO 2.0.0 on a 4 GB ECHO.

    How to read the scores

    Scores range from 0 to 4. A question mark means the sources did not establish support. Rankings use rows with a score for every selected player and show how many rows counted.

    By default each scored row gets the same weight. Pick a priority to count its rows three times. Hardware price, firmware cost, installation, and battery figures stay outside the score. Battery figures are vendor ratings, with no matched runtime, sound quality, or reliability tests across these setups.

    Gnarlyr scores reflect documented development features. Open a cell to see where the evidence comes from, including which features still need player checks. Other firmware versions are listed with each setup. Q2 Pod scores cover its own player and documented add-ons. Rockbox runs separately on the Q2.
