    		 Gnarlyr
    USB copy and reboot

    From FiiO’s firmware, copy Gnarlyr’s ECHOECHO.img to internal storage, eject the drives, unplug, and power the ECHO off and on. If you run Podium, return to FiiO’s firmware first.     Shanling Q2 hardware overview
    Equalizer and imports
    Scoring

    Rewards editable EQ, reusable curves, then parametric filters and import.

    		 Gnarlyr
    410-filter PEQ + AutoEQ*

    Preview graphic EQ and edit ten bands, or build a parametric curve with up to ten filters and adjustable preamp. Save either kind of curve to one of eight slots. Import compatible AutoEQ or Equalizer APO files, or use seven sound-shaping controls on their own or over a saved parametric curve. Local PCM playback supports EQ up to 192 kHz. The wired DACs can apply curves of up to three filters if the DACs can represent the curve at the playback rate. Other local PCM curves use software EQ. USB DAC mode applies only compatible hardware curves to PCM. High-rate EQ and USB EQ still need player checks.

    How to read the scores

    Scores range from 0 to 4. A question mark means the sources did not establish support. Rankings use rows with a score for every selected player and show how many rows counted.

    By default each scored row gets the same weight. Pick a priority to count its rows three times. Hardware price, firmware cost, installation, and battery figures stay outside the score. Vendor battery ratings use their own test conditions. The scores cover features and do not measure runtime, sound quality, or reliability.

    The scores describe the firmware versions in the table. Gnarlyr’s scores include features with software tests and features checked on an ECHO. Q2 Pod scores cover its own player and add-ons. Q2 Pod can launch Rockbox separately.
