Install. Set up. Press play.

Install Gnarlyr from a ready-made GNARLYR.img image, add your music and choose your settings. Later updates use the player’s USB updater.

Start with the firmware file.

A firmware image is a file containing the player’s software. Gather the image, a data cable and your backup before starting.

  • The matching release files. Keep GNARLYR.img with its matching guide and checksum. A checksum is a fingerprint for checking that the file is intact.
  • A computer and a USB data cable. Use a cable that transfers files as well as charging.
  • A charged ECHO and a backup. Copy any music and personal files you want to keep to your computer before the first installation.

For Gnarlyr 1.0 or later, follow updating Gnarlyr. To switch from FiiO’s software, follow first installation.

Install Gnarlyr for the first time.

Recovery mode lets your computer install Gnarlyr before the player’s own updater is running. Use it for the first switch from FiiO’s software.

  1. Prepare your files. Have GNARLYR.img, the full-size ECHO recovery tools and the matching installation guide ready. Keep a copy of FiiO’s original firmware for recovery.
  2. Put the ECHO in recovery mode. Unplug USB and press the recessed RST button with a paperclip. Hold every button except Power, then connect USB while keeping those buttons held.
  3. Follow the recovery installation guide. Follow the full-size ECHO procedure to check the connection, back up the original firmware and install the image. Finish every verification step before restarting.
  4. Start the player. Restart into Gnarlyr and check Settings → About. Let the first library and artwork scan finish before connecting USB again.
Recovery details

The recovery mode is called maskrom. The computer should identify 2207:262d; the matching recovery tool must pass its connection test.

The full procedure is in firmware/docs/device-install.md and firmware/docs/device-recovery.md in the source checkout. It checks both firmware-slot headers and compares two complete backups before installation. It writes and verifies the second slot before the first.

The first recovery installation uses the image’s first 5 MiB. Follow the guide to prepare that file; keep the complete GNARLYR.img for ordinary later updates.

Add music. Make it yours.

Choose your music storage, copy your collection and set up the screen and buttons.

  1. Choose your music storage. Use a FAT32 or exFAT microSD card. Gnarlyr uses a readable card when inserted and internal storage otherwise. Settings → About → Music identifies the active storage.
  2. Copy your music. Open USB mode from Home or Settings and choose USB storage. Connect to your computer if it is not already connected. Copy music to the active music drive in any folder layout. Internal storage and an inserted microSD card appear as separate drives.
  3. Eject and let the library refresh. Eject every ECHO drive and let any library and artwork scan finish. To start a scan yourself, choose Settings → Rescan library.
  4. Choose your look and controls. In Settings, choose Theme, Text size and Orientation. Controls lets you assign playback tap and hold actions. Open Music to browse your collection and start listening.

Your settings stay on internal storage, so inserting or removing a card keeps your preferences.

M4B audiobooks appear on the Audiobooks shelf after a rescan, without needing a special folder. Select a book to resume it, or hold Play to choose a chapter. Audiobook formats and playback →

For the next update, copy one file.

Copy the new image to internal storage, check it and eject the drives. Leave USB connected until the player finishes installing.

  1. Connect in Storage mode. Choose Home → USB mode → USB storage, or open USB mode from Settings. Connect USB if needed, then open the internal-storage drive on your computer.
  2. Copy and check the image. Place the complete GNARLYR.img on internal storage, outside any folders, as its only update file. Check the copied file against the supplied checksum before ejecting.
    Check the copied file on macOS

    Check the copied image · macOS 

    shasum -a 256 "/Volumes/YOUR_ECHO/GNARLYR.img"

    Replace YOUR_ECHO with the internal drive’s actual name. Compare the result with the checksum supplied with the image.

    On macOS, cp -X copies without extra metadata files. Remove any ._GNARLYR.img metadata file from the drive.

  3. Eject every ECHO drive. Eject internal storage and the microSD drive, if present. Keep the cable connected while Gnarlyr checks and installs the image.
  4. Wait for “Update installed.” When that message appears, unplug USB, hold Power for two seconds to switch off, then turn the player back on.
  5. Check the version. Open Settings → About. The update file is removed after a successful installation.

The image belongs on internal storage, even when your music is on microSD.

Eject first. Unplug when it is ready.

Eject finishes the computer’s writes and returns the drives to Gnarlyr. Keep the cable connected during installation, then unplug when the player is ready.

  • Eject all the drives. Returning internal storage and any connected microSD drive lets Gnarlyr check for the update.
  • Leave USB connected during installation. Wait for “Update installed” before removing the cable.
  • Restart after the update. The restart loads the new firmware and its matching USB code together.

For everyday music copying, eject every drive too. Gnarlyr checks for changes and refreshes the library when needed.

After ordinary file copying, wait for the USB mode chooser and select Player to return to your music while leaving the cable connected. Your track, position and queue are kept. Select USB storage to reconnect the drives.

Help and recovery.

Use recovery mode to reinstall firmware when the player cannot start normally.

  • The ECHO will not start. Use the full-size ECHO recovery guide and your saved original firmware. Follow its complete write-and-verify procedure.
  • An update was not recognized. Check that the file is named GNARLYR.img, sits at the top level of internal storage, and is the only update image there.
  • You are using an older custom build. Follow that build’s migration instructions before updating. The older-build reference explains image identities.
  • You want to return to FiiO’s software. Use the full-size ECHO’s official ECHOV200.IMG and its matching return-to-stock instructions. FiiO ECHO firmware ↗
