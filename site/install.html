Start with GNARLYR.img.

Gnarlyr 1.0 will be the first public release. Keep its firmware image, matching installation guide and checksum together when it is available.

You’ll need a charged full-size ECHO, a computer, a USB data cable and a backup of the files you want to keep. A checksum is the image’s fingerprint; it lets you check that a copy is intact.

Switching from FiiO?

The first installation uses the ECHO’s recovery mode. It is a different process from a later USB update.

Back up your files and prepare the full-size ECHO recovery tools before starting. Follow the complete guide to install and verify the image, then restart and check Settings → About. Let the first library scan finish before connecting USB again.

Add your music.

  1. Choose storage. Use a FAT32 or exFAT microSD card, or internal storage without a card. Settings → About → Music shows the active drive. Standard internal storage is named Gnarlyr; a card formatted on the player is named GnarlySD.
  2. Connect and copy. Plug into the computer and choose Connect to computer (the first choice, so just press Play), or open Home → USB mode → Connect to computer. Copy music to the active drive in any folder layout.
  3. Eject and listen. Eject every ECHO drive. Let the library scan finish, choose Charge in USB mode, then open Music. Album covers fill in later while the player is idle.

Choose your Theme, Text size and Controls in Settings. Explore the screens and buttons or add a language pack.

Next time, copy one file.

For Gnarlyr 1.0 and later, put the complete new image on internal storage, even when your music is on microSD.

  1. Copy and check. Choose Connect to computer, then put GNARLYR.img outside any folders on internal storage, as its only update image. Check the copied file against the supplied checksum.
  2. Eject every drive. Eject internal storage and the microSD drive if present. Leave USB connected while the player installs.
  3. Wait, then restart. After “Update installed,” unplug USB, hold Power for two seconds to switch off, then turn it on again. Check the version in Settings → About.

Ejecting finishes the computer’s writes. Restarting loads the new firmware and its matching USB code. The update file is removed after a successful installation.

Check the copied file on macOS

Check the image’s SHA-256

shasum -a 256 "/Volumes/YOUR_ECHO/GNARLYR.img"

Replace YOUR_ECHO with the internal drive’s actual name, usually Gnarlyr, and compare the result with the image’s supplied checksum. On macOS, cp -X avoids extra metadata files; remove any ._GNARLYR.img file beside the image.

Need a hand?

  • Update not recognized: check the filename, internal-storage location and that it is the only update image.
  • Player will not start: use the full-size ECHO recovery guide.
  • Older custom firmware: follow the matching migration procedure before updating.
