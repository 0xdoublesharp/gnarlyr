# Gnarlyr.com

Static firmware website. Serve this directory with any static host; there is no build step, dependency install, external font, or analytics. Open `index.html` directly for a local preview. The home page introduces Gnarlyr; `firmware.html` covers features and fixes, `hardware.html` covers specifications and confirmed findings, and `install.html` guides users through first installation, music setup and later USB updates. `build.html` holds source builds, developer USB workflows and technical migration/recovery references. The main home action goes to Install. All pages share `styles.css` and `site.js`. The script copies commands with success and selection feedback and opens help sections from fragment links. Instructions and expandable help remain available without JavaScript.

The cassette artwork is an original inline SVG, not a device photograph or firmware screenshot. The page includes responsive layouts, keyboard focus, reduced-motion support, readable command wrapping, and native expandable installation help. The [UX pass](../docs/gnarlyr-ux.md) records the accepted design and checks.

Firmware screenshots will be added when ready. Keep final public image assets under `site/assets/`; the publisher includes that directory. Do not add empty screenshot placeholders or claim that the cassette illustration is a screenshot.

DoublePaaS hosting uses the [deployment contract](../docs/deployment.md). Publish the five HTML pages, shared CSS and JavaScript, favicon, robots file and sitemap together. The publisher allows those ten root files and optional image assets; this README and `deploy/` stay outside the served release.

Current firmware content follows the `fresh-base` worktree, reviewed at `ec8dff4`, with the completed AAC timing fix from `c45f854`, rather than the older firmware in this website checkout. Sources include its `notes/gnarlyr-changelog.md`, `docs/stock-firmware.md`, firmware feature/hardware/installation guides, and updater/USB source. The hardware page links FiiO’s published specifications and Cirrus’s chip documentation, and distinguishes those ratings from device readbacks and code analysis. Features inherited from Podium and EchoPod are credited separately from Gnarlyr additions. Build instructions use `tools/firmware.py` and Scratch output.

The first public firmware release will be Gnarlyr 1.0, using the exact image name `GNARLYR.img`. Publish a release version and download only when the firmware is ready. The active firmware task owns producing and accepting that image; this website task does not change firmware or tooling. Legacy names occur only in migration instructions.

The page provides source-build instructions.
