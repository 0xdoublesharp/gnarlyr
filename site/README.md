# Gnarlyr.com

Static firmware website. Serve this directory with any static host; there is no build step, dependency install or external font. Cloudflare adds its analytics beacon to served HTML. Open `index.html` directly for a local preview. The home page introduces Gnarlyr; `firmware.html` covers features and fixes, `hardware.html` covers specifications and confirmed findings, and `install.html` guides users through first installation, music setup and later USB updates. `build.html` holds source builds, developer USB workflows and technical migration/recovery references. The main home action goes to Install. All pages share `styles.css` and `site.js`. The script copies commands with success and selection feedback and opens help sections from fragment links. Instructions and expandable help remain available without JavaScript.

The cassette artwork is an original inline SVG, not a device photograph or firmware screenshot. The page includes responsive layouts, keyboard focus, reduced-motion support, readable command wrapping, and native expandable installation help. The [UX pass](../docs/gnarlyr-ux.md) records the accepted design and checks.

Firmware screenshots will be added when ready. Keep final public image assets under `site/assets/`; the publisher includes that directory. Do not add empty screenshot placeholders or claim that the cassette illustration is a screenshot.

DoublePaaS hosting uses the [deployment contract](../docs/deployment.md). Publish the five HTML pages, shared CSS and JavaScript, favicon, robots file and sitemap together. The publisher allows those ten root files and optional image assets; this README and `deploy/` stay outside the served release.

Firmware references cover main through `013b67f5` and the active `gnarlyr` audio worktree through `72fb3cc0`. Consumer format lists do not promote unconfirmed Vorbis playback. Sources include the matching user guide, hardware notes, codec references and implementation diffs. Hardware ratings link to FiiO and Cirrus; device readbacks retain their unit scope.
