# Theme packs

User-installable themes use `.gtheme` files in `/.gnarlyr/themes/` on the music volume. They carry complete palettes and optional bounded RGB565 artwork, without modifying firmware. The five built-in themes remain available.

See the [community format specification](../../docs/theme-format.md) for the binary layout, manifest, builder, validation, rendering and optional signatures, and the [user guide](user-guide.md#themes-and-controls) for installation and selection. The earlier internal palette-slot `.bin` experiment is superseded by this format.
