# Security

Report vulnerabilities privately with [GitHub's vulnerability reporting form](https://github.com/0xdoublesharp/gnarlyr/security/advisories/new). Include the affected commit or version, a minimal reproducer, expected impact, and any suggested fix. Remove device backups, credentials, and personal music from attachments.

Keep an unpublished vulnerability out of public issues and pull requests while maintainers investigate. We will coordinate a fix and disclosure with the reporter. Development builds have no published support window; include the exact build in every report.

Firmware updates, filesystem writes, image validation, USB commands, recovery boundaries, and desktop-to-device trust are security-sensitive. A valid CRC or SHA-256 checksum establishes integrity, not publisher authenticity.
